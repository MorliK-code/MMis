Main config

Базовые параметры приложения, API, режим запуска и безопасные флаги. Нужные подсказки появляются при наведении на знак вопроса.

Приложение app
app.name?
Название приложения
Показывается в заголовках, логах и UI. Обычно не трогать.
Пример: MMis
default_language?
Язык по умолчанию
Используется как подсказка для ответа, классификации и промпта.
ru / en / uk
debug?
Debug mode
Включать только при отладке: больше логов, больше служебной информации.
false — обычный режим
выключено
API api
host?
Адрес сервера
127.0.0.1 — только текущий ПК. 0.0.0.0 — принимать подключения из локальной сети.
Для другого ПК: 0.0.0.0
port?
Порт API
Порт, на котором FastAPI/uvicorn принимает запросы.
http://127.0.0.1:8027
startup.mode?
Режим запуска
Определяет, как стартует приложение: API, UI или комбинированный режим.
api
LLM / Runtime llm
provider?
Провайдер модели
Основной рантайм генерации. Для локальной Аси сейчас логичнее ollama.
ollama / openai / auto
model_name?
Основная модель
То, чем отвечает основной чат. Должна совпадать с названием в Ollama.
qcwind/qwen3-8b-instruct-Q4-K-M
thinking_enabled?
Reasoning/thinking
Разрешает модели использовать режим рассуждения, если модель это поддерживает. Отдельно от показа thinking в UI.
true — модель может думать
включено
max_tokens bounds?
Границы токенов
Нижняя и верхняя граница бюджета генерации. Удобно не давить reasoning-модели слишком маленьким лимитом.
lower=2048, upper=8192
Memory core memory
memory_core.enabled?
Новая память
Главный переключатель Memory Core. Если выключить — ответы останутся без долговременного retrieval.
true
включено
retrieval.top_k?
Сколько воспоминаний искать
Больше top_k — шире контекст, но выше риск мусора и больше токенов.
8 — хороший баланс
context_budget.memory?
Бюджет памяти в prompt
Сколько токенов можно отдать под найденные факты/эпизоды.
700
summary.trigger?
Когда сжимать диалог
После какого количества сообщений делать summary, чтобы не тащить весь сырой чат.
60 сообщений
Web / Internet internet
web_mode?
Режим веба
auto — искать только когда нужен свежий/внешний факт. on/aggressive — чаще ходить в интернет.
off / auto / on
search.api_url?
SearXNG endpoint
Локальный или серверный endpoint поиска.
http://127.0.0.1:8080/search?format=json
Voice voice
stt_engine?
Распознавание речи
Для локального голосового режима можно использовать faster-whisper.
faster_whisper
tts_engine?
Озвучка ответов
qwen — под локальный Qwen TTS, edge — под системный/сетевой TTS.
qwen
Опасные действия
safety_mode?
Безопасность инструментов
read_only_tools — безопаснее. allow_os_actions — разрешает действия в ОС, лучше включать только вручную.
read_only_tools
